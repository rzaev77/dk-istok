Система льгот

Льготное посещение мероприятий Дворца культуры «Исток».

Для отдельных категорий граждан предусмотрены льготы на посещение платных мероприятий Дворца культуры «Исток». Для получения льготного билета может потребоваться цифровой ID и подтверждающий документ.

Как получить льготу

  • Уточните наличие льготных билетов на конкретное мероприятие в билетной кассе
  • Подготовьте документ, подтверждающий право на льготу
  • При необходимости оформите цифровой ID для льготного посещения
